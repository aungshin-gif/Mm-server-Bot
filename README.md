# Gamepay Hub — MLBB Myanmar Server Bot

Gamepay Hub ရဲ့ အပျင်းပြေ Telegram Bot မှ ကြိုဆိုပါတယ်။

ဒီ Bot မှာ MLBB Myanmar Server diamond service၊ MLBB Region Check နှင့် Hero Tier List service ရရှိနိုင်ပါတယ်။

## Main Features

- Weekly Pass — 6,000 Ks
- KBZPay payment — 09795687480
- MLBB User ID နှင့် Zone ID Region Check
- Hero Tier List — EXP Lane / Tank
- Payment screenshot order system
- Admin Approve / Reject buttons
- Admin Premium custom emoji ID lookup
- User Feedback ကို admin ဆီ sender information နဲ့ forward ပေးခြင်း
